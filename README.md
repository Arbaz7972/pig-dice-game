# 🎲 Pig Game

A simple and interactive **Pig Dice Game** built using **HTML, CSS, and JavaScript**.

## 📌 About The Game

Pig Game is a two-player dice game.

* Players take turns rolling the dice.
* If the player rolls a number from **2 to 6**, it is added to their current score.
* If the player rolls **1**, their current score becomes **0** and the turn changes.
* A player can click **Hold** to add their current score to their total score.
* The first player to reach **100 points** wins the game.

## 🎮 Game Rules

1. Click **Roll Dice** to roll the dice.
2. If the dice shows **2–6**, the number is added to the current score.
3. If the dice shows **1**, the player loses their current score and the turn changes.
4. Click **Hold** to save the current score.
5. The first player to reach **100 points** wins.
6. Click **New Game** to restart the game.
